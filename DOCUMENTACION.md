## Inicio Rápido

### Instalación (3 pasos)

```bash
# 1. Configurar base de datos
configurar_bd.bat

# 2. Compilar
.\mvnw clean compile

# 3. Arrancar
.\arrancar.bat
```

### Primeros Pasos

1. Leer **[INSTALACION.md](docs/INSTALACION.md)** para instalar
