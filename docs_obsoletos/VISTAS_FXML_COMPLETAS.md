## ✨ CARACTERÍSTICAS TÉCNICAS

### Estructura Común de Vistas

```xml
<?xml version="1.0" encoding="UTF-8"?>
<?import javafx.scene.control.*?>
<?import javafx.scene.layout.*?>
<?import javafx.geometry.Insets?>

<VBox xmlns="http://javafx.com/javafx/21" 
      xmlns:fx="http://javafx.com/fxml/1"
      fx:controller="alicanteweb.erp.controller.XXXController"
      stylesheets="@/styles/simple-theme.css"
      spacing="20" 
      style="-fx-background-color: #f8f9fa; -fx-padding: 32;">
    
    <!-- Cabecera con título y botones -->
    <HBox alignment="CENTER_LEFT" spacing="16">
        <Label text="📊 Título del Módulo" styleClass="title"/>
        <Region HBox.hgrow="ALWAYS"/>
        <Button text="Acción" styleClass="button-primary"/>
    </HBox>
    
    <!-- Contenido principal -->
    <VBox styleClass="card" spacing="16">
        <!-- Contenido aquí -->
    </VBox>
    
</VBox>
```

### Clases CSS Utilizadas

```css
.title - Títulos principales
.card - Tarjetas con fondo blanco
.button - Botón estándar
.button-primary - Botón primario (azul)
.button-success - Botón éxito (verde)
.button-danger - Botón peligro (rojo)
.button-warning - Botón advertencia (amarillo)
```
