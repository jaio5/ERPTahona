═══════════════════════════════════════════════════════════════
  ⚠️  POSIBLES PROBLEMAS Y SOLUCIONES
═══════════════════════════════════════════════════════════════

PROBLEMA: "Error conectando a MySQL"
SOLUCIÓN:
   □ Verifica que MySQL esté corriendo
   □ Servicio: MySQL80 debe estar activo
   □ Comando: services.msc → Buscar MySQL80
   □ O ejecuta: net start MySQL80

PROBLEMA: "Error: Base de datos 'tahona' no existe"
SOLUCIÓN:
   □ Abre MySQL Workbench
   □ Ejecuta: CREATE DATABASE IF NOT EXISTS tahona;
   □ Importa: basesdedatos\definitivo\tahonaerp.sql

PROBLEMA: "Error al cargar vista de [módulo]"
SOLUCIÓN:
   □ Verifica que el archivo FXML existe
   □ Ruta: src\main\resources\ui\[modulo]_panel.fxml
   □ Si está vacío, revisa el backup

PROBLEMA: "Puerto 8080 ya en uso"
SOLUCIÓN:
   □ Cambia puerto en application.properties
   □ O mata el proceso: netstat -ano | findstr :8080

PROBLEMA: "No carga datos de la BD"
SOLUCIÓN:
   □ Verifica que la tabla tenga datos
   □ Ejecuta: SELECT * FROM clientes LIMIT 5;
   □ Si está vacía, importa datos de prueba
