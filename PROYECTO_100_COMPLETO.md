## 🚀 INSTALACIÓN COMPLETA

### 1. Scripts SQL (ejecutar en orden):
```bash
cd D:\Programación\ERP

# Base de datos
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS erp_alicante;"

# FASE 1
mysql -u root -p erp_alicante < basesdedatos/fase1_legalizacion.sql

# FASE 2
mysql -u root -p erp_alicante < basesdedatos/fase2_fiscal.sql

# FASES 3-8
mysql -u root -p erp_alicante < basesdedatos/fases_3_8_completas.sql

# Verificar
mysql -u root -p erp_alicante -e "SHOW TABLES;"
```

### 2. Configuración completa (application.properties):
```properties
# Base de datos
spring.datasource.url=jdbc:mysql://localhost:3306/erp_alicante?useSSL=false&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=tu_password
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=false

# Backup automático
backup.path=./backups
backup.retention.days=30

# Notificaciones
notificaciones.email.habilitado=true
notificaciones.email.admin=admin@empresa.com

# Email (Spring Mail)
spring.mail.host=smtp.gmail.com
spring.mail.port=587
spring.mail.username=tu-email@gmail.com
spring.mail.password=tu-app-password
spring.mail.properties.mail.smtp.auth=true
spring.mail.properties.mail.smtp.starttls.enable=true
spring.mail.properties.mail.smtp.starttls.required=true

# VeriFactu
verifactu.certificado.ruta=src/main/resources/certs/mi_certificado.p12
verifactu.certificado.password=tu_password

# Scheduler
spring.task.scheduling.pool.size=5
```

### 3. Compilar y ejecutar:
```bash
# Compilar
mvn clean compile

# Ejecutar tests
mvn test

# Empaquetar
mvn clean package -DskipTests

# Ejecutar
mvn spring-boot:run

# O ejecutar JAR
java -jar target/ERP-0.0.1.jar
```

### 4. Acceso inicial:
