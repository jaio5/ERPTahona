│ ✅ CHECKLIST RÁPIDO                                                      │
└──────────────────────────────────────────────────────────────────────────┘

  Antes de arrancar, verifica:

  ☐ Java 17+ instalado (java -version)
  ☐ Maven instalado (mvn -version)
  ☐ MySQL ejecutándose (net start mysql)
  ☐ Base de datos 'tahona' creada
  ☐ Credenciales en application.properties

  Para arrancar:

  ☐ Doble clic en arrancar.bat
    o
  ☐ Ejecutar: mvn javafx:run


┌──────────────────────────────────────────────────────────────────────────┐
│ 🆘 SOPORTE RÁPIDO                                                        │
└──────────────────────────────────────────────────────────────────────────┘

  Error más común: "Cannot connect to database"
  → Solución: GUIA_ARRANQUE.md (busca "MySQL")

  Error: "Java version incompatible"
  → Solución: Instalar Java 17+

  Error: "JavaFX not found"
  → Solución: Usar mvn javafx:run (no java -jar)

  La app arranca pero no hay datos:
  → Solución: Verificar que MySQL tiene datos
             SELECT COUNT(*) FROM clientes;
